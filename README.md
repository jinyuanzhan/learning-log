# learning-log

记录我的学习与求职准备过程：过去学过的、正在学的、未来要学的，都放在这里。

## 目录

| 文件夹 | 用途 |
|---|---|
| [roadmap.md](roadmap.md) | 学习路线图：已完成 / 进行中 / 未来要学 |
| journal/ | 学习日志，按月记录（仅本地，不公开） |
| [notes/](notes/) | 按主题整理的知识笔记 |
| ├ [algorithms/](notes/algorithms/) | Data structures & algorithms, LeetCode |
| ├ [cs-basics/](notes/cs-basics/) | OS, networking, databases |
| ├ [ml-llm/](notes/ml-llm/) | Machine learning, LLMs |
| └ [robotics/](notes/robotics/) | Robotics, control, motion planning |
| interview/ | 常见题、项目讲解稿、面经复盘（仅本地，不公开） |
| [projects/](projects/) | 做过的项目的总结和亮点 |
| CV/ | 简历、Cover letter（仅本地，不公开） |
| [thinking/](thinking/) | 思考记录：还没想清楚的问题、想法、反思 |
| [assets/](assets/) | 图片等附件 |

## 使用 Obsidian

整个仓库可以直接作为 Obsidian 的 vault 打开：

1. Obsidian → Open folder as vault → 选择本仓库文件夹。
2. 设置 → 文件与链接 → 附件默认存放路径：`assets`。

笔记都是普通 Markdown，在 GitHub 上也能正常显示。
