## 使用 Obsidian

整个仓库可以直接作为 Obsidian 的 vault 打开：

1. Obsidian → Open folder as vault → 选择本仓库文件夹。
2. 设置 → 文件与链接 → 附件默认存放路径：`assets`。
3. 设置 → 核心插件 → 模板 → 模板文件夹位置：`templates`。

笔记都是普通 Markdown，在 GitHub 上也能正常显示。
